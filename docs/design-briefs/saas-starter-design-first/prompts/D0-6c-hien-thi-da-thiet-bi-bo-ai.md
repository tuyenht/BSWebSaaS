# D0-6c · Hiển thị đa thiết bị — rà & sửa màn đã có (phần 3: bộ AI)

- Sửa: cột xếp chồng → thẻ gọn · độ ưu tiên CSS (quy tắc hẹp phải thắng) · hộp thoại → trượt từ đáy/toàn màn · cuộn ngang trang · chữ bị cắt · vùng bấm < 44px · thứ chỉ hiện khi rê chuột · 100vh → 100dvh · thanh Lưu/nút nổi che nội dung. Mã màu cứng ở phần sửa → token.
- Chụp khung 390 và 768 đặt cạnh khung máy tính trong canvas của màn.
Giao nộp: README có bảng "Kiểm hiển thị" từng màn (bề rộng × trình duyệt → đạt/chưa + lý do); mục "Việc cho backend" liệt kê màn ĐÃ BUILD trong repo phải sửa theo (tra sổ màn trong Admin Shell / `docs/saas-starter-screen-map.md`), ghi rõ khác biệt để Claude Code port.
